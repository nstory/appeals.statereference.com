{%- comment -%} The filters: one fieldset per Pagefind filter, named in data-filter. The boxes live outside the form and carry no `name`, so they're JS-only: search.js turns each fieldset into ?type=, ?sub_type= or ?year= and fills in each count from the index. Each box's value is the URL slug; data-value is the exact Pagefind filter value -- for a type or a year, as the Cases plugin reads it from cases.jsonl; for a stage, its value from _data/sub_types.yml, whose label rides in data-label for the summary line. From md up it's a plain sidebar. Below that, offcanvas-md turns the same markup into a drawer, opened by the Filters button beside the sort control, so a phone shows results first rather than a list to scroll past. The drawer's header, title and close button only exist below md. {%- endcomment -%}
